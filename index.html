🔐 تنبيه حماية قواعد Realtime Database

لكي يعمل تطبيق الأندرويد دون الحاجة لتسجيل دخول كل مستخدم، يجب أن تكون القراءة (.read) مسموحة، بينما الكتابة (.write) مقتصرة على حساب المشرف فقط (عبر الـ UID): 
{
  "rules": {
    ".read": true,
    ".write": "auth != null && auth.uid === 'YOUR_ADMIN_UID'"
  }
}
